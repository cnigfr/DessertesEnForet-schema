# Tronçon de route

**Définition** : Classe générique des tronçons de route. Les propriétés de cette classe constituent le socle commun à l’ensemble des linéaires du standard, qu’il s’agisse d’itinéraires bois rond, de dessertes forestières, de voies DFCI ou d’autres types de voie.

**Critères de sélection** : Toutes les routes sur lesquelles un véhicule peut circuler (ne sont pas concernés les chemins pédestres) et qui : 
- ne relèvent pas de données sensibles ;  
- sont anonymisées ;
- sont diffusables en Open Data ;
- ont été validées par les autorités compétentes comme ayant un intérêt opérationnel stratégique pour la DFCI ou opérationnel pour le transport de bois.

**Modélisation géométrique** : Linéaire simple (les éléments relatifs à l'origine de saisie de la géométrie, sa précision ou sa qualité sont précisés dans les métadonnées).
