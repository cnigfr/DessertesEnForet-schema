# Itinéraire bois rond

**Définition** : Classe des itinéraires autorisés par arrêté préfectoral pour le transport de bois ronds. Les tronçons de cette classe sont renseignés par les attributs du socle commun [Tronçon de route](../classe-troncon-route/README.md), ainsi que par les attributs spécifiques à cette classe permettant de renseigner les conditions à respecter pour emprunter les routes autorisées pour le transport de bois ronds. 

**Critères de sélection** : Ces attributs ont les mêmes critères de sélection que les tronçons de route et sont à renseigner seulement lorsque l’attribut Réseau transport de bois (de la classe d’objet Tronçon de route) a été renseigné avec la valeur « Itinéraire Bois Rond ». 

**Modélisation géométrique** : Linéaire simple.

**Propriétés de la classe Itinéraire bois ronds** : Cf. propriétés héritées de la classe [Tronçon de route](../classe-troncon-route/README.md). On indique ici seulement les propriétés additionnelles.
